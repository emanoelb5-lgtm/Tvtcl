# TCL Light — Launcher para Android TV

Launcher leve e offline em Kotlin para TVs TCL, desenvolvido para navegação com controle remoto.

> Projeto inicial em desenvolvimento. Teste o aplicativo antes de tentar usá-lo como tela inicial padrão.

O APK é compilado automaticamente em **Actions → Compilar APK TCL Light** e disponibilizado como artefato da execução.
